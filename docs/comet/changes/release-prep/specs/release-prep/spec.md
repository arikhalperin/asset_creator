# Release Preparation

## Purpose

Make Game Asset Creator distributable and dependable: a self-contained macOS app, documentation, a headless smoke test with CI, and a UI that never freezes during extraction.

## Requirements

### Performance

- Remove Background (`keying`) and Auto-Detect (keying + detection) previews and commits run on worker threads. The UI shows "Working…" while a result is pending; a newer request supersedes an older one (the older result is discarded); Cancel restores the layer immediately and drops pending work. Results equal the previous synchronous ones.
- Model and PDFium downloads show progress and a Cancel button; cancelling stops the transfer and removes partial files.
- Extract Frames' Cancel signals the worker and returns without joining it.
- A release test runs Extract Assets on a 1-minute fixture clip in the headless harness, recording every frame's duration, asserting each < 50 ms, progress monotonic to 100 %, and that Cancel ends the run within 1 s.
- Existing release benchmarks keep their limits.

### Packaging

- `scripts/package-macos.sh [--skip-ffmpeg-build]`: (1) builds ffmpeg (pinned release tarball, SHA-256 checked) with `--disable-gpl --disable-nonfree --disable-programs --disable-encoders --disable-muxers --disable-network --enable-shared` (decoders, demuxers, swscale, swresample kept) into a cache under `target/`; (2) downloads ONNX Runtime for osx-arm64 (pinned version compatible with the `ort` crate, SHA-256 checked); (3) `cargo build --release` with `PKG_CONFIG_PATH` pointing at the built ffmpeg; (4) assembles `target/package/Game Asset Creator.app` with `Contents/MacOS/game-asset-creator`, `Contents/Frameworks/*.dylib`, `Contents/Resources/AppIcon.icns` and `sample.mp4`, `Contents/Info.plist` (CFBundleIdentifier `io.github.game-asset-creator`, version 1.0.0, LSMinimumSystemVersion 13.0, high-resolution capable); (5) rewrites install names to `@rpath/…` with an `@executable_path/../Frameworks` rpath; (6) ad-hoc signs (`codesign --force --deep --sign -`); (7) writes `.zip` (ditto) and `.dmg` (hdiutil) to `target/package/`; (8) runs the bundle checks (otool references, ffmpeg configuration, codesign verify, `--self-test`) and fails on any problem.
- ONNX Runtime search order: `ORT_DYLIB_PATH`, the app bundle's `Contents/Frameworks/libonnxruntime.dylib`, then the existing system paths.
- `game-asset-creator --self-test`: no window; decodes the first frame of `Resources/sample.mp4` (bundled) or a given file, creates an ONNX Runtime environment from the bundled dylib, prints the versions, exits 0 on success and non-zero with a reason otherwise; reads and writes nothing in the user's data directories.
- Icon: `assets/icon/icon.svg` → `assets/icon/AppIcon.icns` (generated by a script from the SVG; committed).

### Documentation

- README.md: overview, features, install (download, first launch via right-click ▸ Open), models on first use, building from source, packaging, smoke test and CI, licence summary.
- docs/user-guide.md: text walkthrough video → Extract Assets → Review → Library (tags, categories) → export single/sets/sprite sheets with atlas; plus editor basics, Extract Object, patterns, PDF parts layout, recolour, enhance lines; models table (name, size, source, storage path, how to delete); keyboard shortcuts.
- THIRD_PARTY_NOTICES.md: ffmpeg (LGPL-2.1+, source URL and configure flags), ONNX Runtime (MIT), PDFium (BSD-3/Apache-2.0), MobileSAM (Apache-2.0), OpenCLIP ViT-B/32 LAION-2B (MIT), Rust crate licences summary.
- A test parses the guide for menu paths written as `Menu ▸ Item` and checks each exists in the headless UI.

### Smoke test and CI

- tests/smoke.rs (offline, GrabCut-only segment config, temporary library): image → filter → Remove Background → add to library → export PNG + save project; video → Extract Assets → review → add → export sprite sheet with atlas; asserts the files exist and decode.
- scripts/smoke.sh: runs `cargo test --release --test smoke`.
- .github/workflows/ci.yml: on push/pull_request, `macos-14` runner, `brew install ffmpeg onnxruntime pkg-config`, then `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, `scripts/smoke.sh`.
